# Desafio Sicredi [Estágio] — Processo Seletivo 2022

> Três mini‑projetos em **HTML + CSS + JavaScript** que desenvolvi durante o desafio técnico que me abriu as portas para o time do Sicredi.

## Visão geral

| Arquivo | Descrição resumida |
|---------|--------------------|
| `index.html`       | Landing simples que linka os três desafios |
| `desafioone.html`  | Primeiro exercício (DOM + lógica básica) |
| `desafiotwo.html`  | Segundo exercício (manipulação de dados) |
| `desafiothree.html`| Terceiro exercício (interatividade extra) |
| `scripts/`         | JS separado por desafio |
| `styles/`          | CSS modular para cada página |
| `logoSicredi.svg`  | Logomarca oficial usada no teste |

## Tecnologias

- **HTML 5**
- **CSS 3** (Flexbox/Grid)
- **JavaScript ES6**  
  (sem frameworks—vanilla mesmo)
